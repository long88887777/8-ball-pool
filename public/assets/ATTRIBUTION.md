# Pool table asset attribution

The table geometry in `pool-table.glb` is rebuilt from **Billiard tables** by
dpapavas, downloaded from OpenGameArt:

- Source: https://opengameart.org/content/billiard-tables
- License: GNU General Public License 3.0
- Changes: isolated the pocketed tournament-spec table from the source Blend,
  removed the legs and room furniture, normalized its four tabletop meshes to
  the game's 1100×640 coordinate space, separated the cloth and cushion
  materials, added recessed pocket bottoms, and added reference-matched corner
  guards and rail sights.

The previous BrightRetro CC-BY 3.0 candidate remains only in the dated QA
research folders and is no longer shipped as the active game table.

The generated cloth and mahogany base-color tiles are project-specific derived
assets created to match the supplied visual reference.
