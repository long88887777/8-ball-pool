# Main Menu Interface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a main menu screen with three mode buttons (VS AI, Two Players, Challenge) that appears before the game loads.

**Architecture:** HTML/CSS overlay that covers the viewport on page load. Clicking a mode button hides the menu, reveals the game shell, and initializes Phaser with the selected mode passed via game registry. The existing PoolScene reads the mode from the registry instead of defaulting.

**Tech Stack:** HTML, CSS (animations, gradients), TypeScript, Phaser 3 game registry

### Task 3: Wire Up Menu Logic in main.ts

**Files:**
- Modify: `src/main.ts` (rewrite to defer Phaser init)

- [ ] **Step 1: Replace src/main.ts contents**

```typescript
import Phaser from 'phaser';
import { PoolScene } from './game/PoolScene';
import './styles.css';

type GameMode = 'pvp' | 'ai' | 'challenge';

function startGame(mode: GameMode): void {
  const menu = document.getElementById('main-menu');
  const shell = document.querySelector<HTMLElement>('.game-shell');
  if (menu) menu.hidden = true;
  if (shell) shell.hidden = false;

  const config: Phaser.Types.Core.GameConfig = {
    type: Phaser.AUTO,
    parent: 'game',
    width: 1100,
    height: 640,
    backgroundColor: '#10100e',
    scene: [PoolScene],
    physics: {
      default: 'matter',
      matter: {
        gravity: { x: 0, y: 0 },
        debug: false,
      },
    },
    scale: {
      mode: Phaser.Scale.FIT,
      autoCenter: Phaser.Scale.CENTER_BOTH,
    },
    callbacks: {
      preBoot: (game) => {
        game.registry.set('initialMode', mode);
      },
    },
  };

  new Phaser.Game(config);
}

document.querySelectorAll<HTMLButtonElement>('.menu-btn').forEach((btn) => {
  btn.addEventListener('click', () => {
    const mode = btn.dataset.mode as GameMode;
    startGame(mode);
  });
});
```
